Customization

Dashboard, overlay, preferences, and runtime paths.

This page groups the user-facing controls that shape how the app behaves after configuration is complete.

Dashboard

  • Open the game grid with Show Dashboard.
  • Use search to filter games quickly.
  • Filter by platform and sort by name, progress, or last update time.
  • Click a game card to load its config.
  • Use Ctrl + Click or the card context menu to select multiple games, then ignore, delete, or clear the selection from the action bar.
  • Enable Show blacklisted games to inspect and restore ignored games.
  • Use the play button for games with configured executables.
  • Background polling can auto-select the active game when its process starts.
  • Esc or the close button restores the main UI and input state.

Customization

  • Choose notification preset and screen position.
  • Choose Native Windows to use Windows toast notifications instead of an animated preset.
  • Select notification sounds and language.
  • Select which achievement schema languages are generated from Settings - Advanced - Achievements Schema Languages.
  • Adjust UI scale from 75% to 200%.
  • Adjust achievement duration and sound volume.
  • Toggle hidden descriptions when available.
  • Enable Close to Tray.
  • Configure overlay shortcut and interaction key.
  • Configure Notification Click Action to open the matching achievement in the non-focusable overlay or in the main application. Opening the main application moves focus away from the game.
  • Native Windows notifications retain independent navigation routes in Action Center, allowing each available notification to open its own achievement.
  • Enable or disable overlay controller support from Settings → Advanced → Rendering.
  • Enable or disable achievement screenshots, achievement records, progress notifications, playtime notifications, and startup behavior.
  • Mute progress notifications independently for the active game config.
  • Use Start with Windows to create or remove the Task Scheduler entry for the current executable.
  • Disable the native process watcher to use executable-name fallback detection through ps-list. Command-line arguments are unavailable in fallback mode.

Xbox Game Bar notifications

  • The optional Xbox Game Bar companion Achievements Overlay by JokerVerse can deliver native Game Bar notifications.
  • Delivery includes achievement unlocks, rarity or platinum metadata, click navigation, and textual progress in current / maximum • percentage format.
  • The companion is optional. If it is not installed or connected, the Electron application remains independent and uses the configured notification fallback.

Achievement records

  • Enable achievement recording to save a short clip around each unlock.
  • Select 30 or 60 FPS.
  • Choose a total duration from 10 to 30 seconds, divided equally before and after the unlock.
  • Recording captures the default Windows output mix. If system audio is unavailable, recording safely falls back to video only; microphone input is not captured.
  • Optional GPU HDR-to-SDR conversion keeps H.264/MP4 clips compatible with standard SDR players.

Changelogs

  • Settings - Changelogs lists GitHub releases with version, release type, publication date, and release notes.
  • Release data is cached for 30 minutes. Refresh requests current data while the last valid cache remains available offline.
  • Release links open GitHub in the default browser. Remote release text is displayed as text and is not executed as HTML.

Live logs

  • Settings - Logs lists known application logs and discovers additional .log files in the logs directory.
  • The selected file is followed in real time across replacement, truncation, and normal log rotation.
  • Search and DEBUG, INFO, WARN, or ERROR filters affect only the displayed lines.
  • Pause pauses UI updates, Clear View clears only the in-memory view, and Open Logs Folder opens the source files.
  • The initial view contains at most 1,000 recent lines and the UI retains at most 2,000. Monitoring runs only while the Logs tab is active.
  • Logs can contain local paths or account identifiers. Review them before sharing publicly.

Keyboard and controller highlights

  • Controller Support includes a Dashboard introduction and controller navigation.
  • Multi-Platform Support V2 + Overlay Controller Support also includes the overlay controller support flow.

Global

Settings: F1 / Ctrl+O. Dashboard: F2 / Ctrl+D. Play: P / Ctrl+Enter.

Overlay

Toggle visibility with the configured overlay shortcut. Toggle interaction mode with the configured interact key.

Overlay controller mode

Xbox: View + Menu toggles overlay, hold LB + RB for control mode. PlayStation uses Share + Options and L1 + R1.

Main screen

Create New Config with Ctrl+N. Toggle options with F3. Navigate with arrow keys or controller D-pad.
